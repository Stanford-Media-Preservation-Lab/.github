# Stanford Media Preservation Lab

As part of our audiovisual preservation work, we create and maintain scripts and tools that support audiovisual digitization, preservation, and quality control at Stanford Media Preservation Lab.

## Repositories

| Repository | Description |
|---|---|
| [checksum-tools](https://github.com/Stanford-Media-Preservation-Lab/checksum-tools) | This tool creates and verifies checksums in audiovisual preservation environments |
| [cta](https://github.com/Stanford-Media-Preservation-Lab/cta) | This tool creates and validates tarball archives from directories chock full of digital objects |
| [smpl_interstitial](https://github.com/Stanford-Media-Preservation-Lab/smpl_interstitial) | Detects interstitial errors (dropped samples) in audio digitization |
| [srd](https://github.com/Stanford-Media-Preservation-Lab/srd) | Moves files securely network storage and local storage or from drive to drive |
| [srw](https://github.com/Stanford-Media-Preservation-Lab/srw) | Takes digitized motion picture film packages and prepares them for long-term storage |
| [vdg](https://github.com/Stanford-Media-Preservation-Lab/vdg)) | Creates various types of derivative files for preservation and access |
